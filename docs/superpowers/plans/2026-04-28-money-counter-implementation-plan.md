# 工资实时回血工具实施计划

日期：2026-04-28

依据规格文档：[工资实时回血工具产品设计](../specs/2026-04-28-money-counter-design.md)

## 0. 计划边界

本计划只覆盖从技术验证到公开 Beta 的实施路径，不包含正式商业化、主题商店、账号系统、云同步和 macOS 版本。

核心约束：

- Windows 优先。
- 完全离线可用。
- 无账号、无默认埋点。
- 体积小、资源占用少、常驻稳定。
- Tauri 优先，只有在核心能力被阻塞时才评估 Electron。
- MVP 不做严肃薪资核算，不做窗口/键鼠监控。

## 1. 阶段总览

### Phase 0：技术 Spike

目标：验证 Tauri 是否能满足 Windows 常驻小工具的关键能力和轻量预算。

验收标准：

- 能创建 Windows 托盘入口。
- 能打开/隐藏主面板。
- 能实现通知。
- 能实现开机自启开关。
- 能保存本地设置。
- 能复制图片到剪贴板或保存图片。
- 能打包出 Windows 安装包或便携包。
- 粗测安装包体积、常驻内存、空闲 CPU、冷启动时间。

### Phase 1：P0 可用原型

目标：跑通“设置 -> 计算 -> 托盘常驻 -> 主面板 -> 状态切换”的主链路。

验收标准：

- 用户可以完成首次配置。
- 月薪、时薪、日薪三种输入可计算。
- 标准工时和弹性工时可工作。
- 自动/开工/摸鱼/午休/暂停/收工状态可切换。
- 主面板实时显示今日已赚、每秒到账、今日预计、已工作时长。
- 托盘显示可随隐私模式变化。
- 跨天和睡眠唤醒后状态不明显错误。

### Phase 2：P1 内测版

目标：补齐隐私、提醒、轻角色、分享图、本地统计开关和反馈能力，交给 20-50 个种子用户测试。

验收标准：

- 四种隐私显示模式可用。
- 低频提醒可配置、可关闭、有勿扰时间。
- 轻角色有基础状态和简单动画。
- 三个分享模板可生成图片、保存图片、复制图片。
- 分享图默认不暴露月薪，带弱引流标识。
- 本地统计默认关闭，用户可主动开启。
- 一键清空本地数据可用。
- 有反馈入口或反馈说明。

### Phase 3：P2 公开 Beta

目标：提供可公开下载的 Windows 版本和官网/H5 引流页，开始验证外部增长指标。

验收标准：

- 生成可分发安装包或便携包。
- 官网落地页说明产品、隐私、轻量目标、下载方式和 FAQ。
- H5 页面可以承接分享图里的弱引流。
- 内测反馈中的高优先级问题已处理。
- 有基本版本号、更新说明和已知问题列表。

## 2. 工作流拆分

## 2.1 桌面壳与系统集成

职责：

- Tauri 项目初始化。
- Windows 托盘。
- 主窗口显示/隐藏。
- 窗口位置和尺寸记忆。
- 通知。
- 开机自启。
- 剪贴板和图片保存。
- 打包配置。

关键风险：

- 托盘文本和图标在 Windows 上的表现限制。
- Windows 托盘隐藏区导致用户看不到入口。
- 通知权限和勿扰模式。
- 开机自启在不同权限环境下的行为。
- SmartScreen 和杀软误报。

验证任务：

- 在 Windows 10 和 Windows 11 都跑一轮。
- 多显示器和不同缩放比例测试。
- 睡眠唤醒后托盘和窗口仍正常。

## 2.2 计算核心

职责：

- 收入模式：月薪、时薪、日薪。
- 工作制：标准单班、弹性工时、单双休/大小周、自定义工作日。
- 今日有效计薪秒数。
- 今日已赚、每秒收入、今日预计、摸鱼收益。
- 金额格式化和隐私格式化。

实现原则：

- 尽量写成纯函数。
- 不依赖 UI。
- 不依赖系统托盘。
- 单元测试覆盖主要边界。

测试场景：

- 09:00-18:00，午休 90 分钟。
- 当前时间早于上班、处于午休、晚于下班。
- 周末不计薪。
- 单休、双休、大小周。
- 弹性工作制目标 8 小时。
- 月薪为 0、工作日为 0、异常时间配置等输入校验。

## 2.3 状态调度

职责：

- 自动状态判断。
- 手动状态覆盖。
- 恢复自动。
- 午休开始/结束。
- 收工。
- 跨天重置。
- 睡眠唤醒后重新计算。

状态规则：

- 自动状态根据工作制和时间节点决定。
- 手动状态优先于自动。
- 到下一个明确时间节点，或用户手动恢复自动后，回到自动状态。
- 摸鱼状态仍计薪，但单独累计摸鱼收益。
- 午休和暂停默认不计薪。

测试场景：

- 开工后手动摸鱼。
- 午休开始时自动切午休。
- 午休结束后恢复开工。
- 手动收工后不继续计薪。
- 跨天后重新进入新一天。

## 2.4 本地数据与隐私

职责：

- 设置保存。
- 隐私模式保存。
- 提醒配置保存。
- 本地统计开关。
- 本地数据清空。
- 可选匿名摘要导出。

数据原则：

- 默认只保存配置。
- 历史统计默认关闭。
- 用户明确开启后才记录历史。
- 不上传任何客户端行为。
- 不保存不必要的大日志。

本地数据类型：

- `settings`：收入、工作制、显示模式、主题、提醒。
- `day_state`：当天状态、摸鱼累计、暂停累计。
- `local_stats`：仅在用户开启本地统计后写入。
- `achievements`：本地成就进度。

## 2.5 前端界面

职责：

- 首次设置向导。
- 主面板。
- 状态切换控件。
- 设置页。
- 隐私模式设置。
- 提醒设置。
- 分享图入口。
- 本地统计开关。

界面原则：

- 信息密度适中，不能像财务软件。
- 主数字明确，但隐私模式可切。
- 状态切换要一眼可懂。
- 设置项不要一次铺满，优先分组。
- 不做营销落地页式界面。

P0 页面：

- 首次设置向导。
- 主面板。
- 基础设置页。

P1 页面：

- 分享生成页。
- 提醒设置页。
- 本地统计设置。
- 关于与反馈页。

## 2.6 轻角色与文案系统

职责：

- 默认轻角色。
- 状态对应表情/动画。
- 文案配置。
- 主题扩展结构预留。

实现原则：

- 不使用重型动画方案。
- 默认角色资源要小。
- 文案不要硬编码到业务逻辑。
- 常驻文案温和，触发文案有梗，分享文案更强视觉感。

MVP 状态：

- 开工。
- 摸鱼。
- 午休。
- 快下班。
- 加班低电量。
- 收工。

## 2.7 提醒与成就

职责：

- 上班提醒。
- 午休提醒。
- 快下班提醒。
- 喝水、站立、上厕所、眨眼随机提醒。
- 勿扰时段。
- 提醒总开关和分类开关。
- 本地成就。

实现原则：

- 默认低频。
- 不连续弹窗。
- 语气陪伴，不说教。
- 用户能关闭所有提醒。

## 2.8 分享图生成

职责：

- 今日打工战报。
- 摸鱼回血账单。
- 下班生存卡。
- 主题选择。
- 随机文案。
- 隐私模式应用。
- 保存图片。
- 复制图片。
- 弱引流标识。

技术原则：

- 按需生成。
- 不后台预渲染。
- 图片导出结果在高 DPI 下清晰。
- 分享图默认不暴露月薪。
- 弱引流样式不要像广告。

## 2.9 官网/H5 增长页

职责：

- 产品介绍。
- 在线估算体验。
- 下载入口。
- 隐私承诺。
- FAQ。
- 渠道链接统计。

边界：

- H5 可以联网，桌面客户端不依赖它。
- H5 指标只统计网页行为，不代表客户端内行为。
- 不和桌面端账号打通。

## 3. 测试计划

### 单元测试

覆盖：

- 收入换算。
- 工作制计算。
- 状态机。
- 隐私格式化。
- 边界输入。

### 桌面集成测试

覆盖：

- 托盘入口。
- 主窗口显示/隐藏。
- 通知。
- 开机自启。
- 本地设置读写。
- 剪贴板复制图片。
- 图片保存。

### 手工系统测试

覆盖：

- Windows 10。
- Windows 11。
- 100%、125%、150% 缩放。
- 多显示器。
- 睡眠唤醒。
- 跨天。
- 离线使用。
- 低权限办公电脑。

### 体验测试

覆盖：

- 首次配置是否能 1 分钟内完成。
- 托盘显示是否足够低打扰。
- 文案是否好笑但不尴尬。
- 分享图是否愿意发。
- 提醒是否烦。

## 6. 关键风险与应对

### 资源占用不达标

应对：

- 技术 Spike 先测。
- 控制依赖。
- 降低动画复杂度。
- 分享图按需生成。
- 必要时减少前端框架和 UI 库体积。

### Windows 托盘体验受限

应对：

- 托盘图标和提示文本并用。
- 主面板入口清晰。
- FAQ 说明托盘隐藏区。
- 可选悬浮小窗作为补偿。

### 分享图传播弱

应对：

- 先用静态图测试文案和模板。
- 保留 3 个强模板，不做模板海。
- 收集用户投稿文案。
- 弱水印样式 A/B 测试。

### 用户担心隐私

应对：

- 官网和 App 内明确离线、本地、不上传。
- 默认模糊金额。
- 分享图默认不暴露月薪。
- 一键清空本地数据。

### MVP 范围膨胀

应对：

- P0 只做主链路。
- 轻角色只做状态动画。
- 本地统计和悬浮窗作为可裁剪项。
- 不提前做付费系统。

## 7. 进入开发前的待确认项

- 最终项目技术栈是否直接采用 Tauri 2。
- 前端框架选择：轻量 React/Vue/Svelte 或原生 Web。
- 是否 P0 就包含悬浮小窗。
- 默认产品代号。
- 默认角色视觉方向。
- Windows 安装包优先安装版还是便携版。
- 第一批内测用户来源。
