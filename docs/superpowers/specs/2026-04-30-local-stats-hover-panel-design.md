# 本地统计悬停面板设计

日期：2026-04-30

## 1. 目标

在已完成的 `localStatsEnabled` 本地统计开关基础上，增加轻量的本地统计记录与查看能力。第一版只做每日汇总、近 7 天摘要、最近 30 天保留和主面板悬停查看，不做完整统计页、趋势图、成就系统或导出。

## 2. 范围

本轮实现范围：

- 本地统计开关开启后才记录数据。
- 记录每日汇总，最多保留最近 30 天。
- 应用运行中定期写入当天记录。
- 跨天时补写上一天并创建新一天记录。
- 应用退出或主窗口关闭前尽量补写当前记录。
- 主面板显示一个小统计入口，仅在本地统计开启时显示。
- 鼠标悬停或键盘 focus 到入口时显示摘要面板。

本轮不做：

- 独立统计页面。
- 7/30 天趋势图。
- 成就徽章。
- 匿名摘要导出。
- 云同步或上传。
- 分享图内统计模板。

## 3. 数据设计

Store 中新增 `localStats` 记录，结构为每日汇总数组：

```json
[
  {
    "date": "2026-04-30",
    "used": true,
    "paidSeconds": 14400,
    "fishingSeconds": 1800,
    "earned": 320.5,
    "shareCount": 2,
    "updatedAt": "2026-04-30T10:30:00.000Z"
  }
]
```

字段含义：

- `date`：本地日期，格式 `YYYY-MM-DD`。
- `used`：当天是否有统计记录。
- `paidSeconds`：当天有效计薪秒数，来自当前工作指标。
- `fishingSeconds`：当天摸鱼计薪秒数，来自当天状态。
- `earned`：当天回血估算，来自当前工作指标。
- `shareCount`：当天复制或保存分享图次数。
- `updatedAt`：最后写入时间，用于排查和后续导出。

保留策略：

- 每次写入后按日期去重。
- 同一天记录覆盖更新。
- 只保留日期最新的 30 条。

## 4. 写入规则

只有 `settings.localStatsEnabled === true` 时写入。

写入触发：

- 运行中定期写入当天记录，建议间隔 60 秒。
- 跨天时先写入上一天当前状态，再进入新一天记录。
- 复制或保存分享图成功后，增加当天 `shareCount`。
- 主窗口关闭转隐藏或应用退出前，尽量写入一次当前记录。

关闭本地统计后：

- 不继续写入新统计。
- 已有历史记录保留在本机，除非用户使用清空本地设置。
- 摘要入口隐藏。

清空本地设置后：

- 清空 `localStats`。
- `localStatsEnabled` 恢复为 `false`。

## 5. 摘要计算

摘要面板展示最近 7 天数据，基于 `localStats` 中日期最新的 7 天范围计算：

- 近 7 天使用：`used === true` 的天数。
- 近 7 天回血：7 天内 `earned` 总和，按当前隐私显示规则展示。
- 近 7 天摸鱼：7 天内 `fishingSeconds` 总和，格式如 `2h15m`。
- 数据保留：固定显示“最近 30 天”。

空状态：

- 本地统计开启但还没有记录时，显示“开启后开始记录，最多保留 30 天。”

## 6. UI 设计

入口：

- 放在主面板操作区，与设置、状态、复制分享图等图标按钮同组。
- 仅在本地统计开启时显示。
- 使用简单线性统计图标，保持当前 SVG 图标风格。
- 入口具备 `aria-label="查看本地统计"`。
- 鼠标悬停、键盘 focus 时打开面板。

面板：

- 小型悬停面板，不跳转、不打开新窗口。
- 固定宽度约 `260px`，避免内容变化导致主面板抖动。
- 显示：
  - 今日记录：已记录 / 暂无记录。
  - 近 7 天使用：X 天。
  - 近 7 天回血：按隐私规则格式化。
  - 近 7 天摸鱼：XhYm。
  - 数据保留：最近 30 天。
- 面板不包含复杂图表。

视觉：

- 延续当前深色小组件。
- 扁平风格，使用边框和背景层次，不使用重阴影。
- 使用当前色系：深绿底、青绿色高亮、浅色文字、黄色点缀。
- 使用 `opacity` 和 `transform` 做 150-200ms 过渡。
- 不使用表情符号作为结构图标。

可访问性：

- 面板也在键盘 focus 时显示。
- 入口有明确 `aria-label`。
- 面板内容为文本，不只靠颜色表达。
- focus ring 保持可见。

## 7. 错误处理

- Store 读取失败时，使用空统计数组，不阻塞主面板。
- Store 写入失败时，在控制台记录 warning，不打断实时计数。
- 统计数据字段缺失或类型异常时，摘要计算按 0 处理。
- 日期重复时，以最新写入记录为准。

## 8. 测试策略

纯函数测试：

- 合并当天记录。
- 只保留最新 30 天。
- 计算近 7 天摘要。
- 空数据返回空状态。
- 异常字段按 0 处理。

静态 UI 测试：

- 主面板存在统计入口。
- 入口默认可被隐藏。
- 入口有 `aria-label`。
- 面板包含近 7 天使用、近 7 天回血、近 7 天摸鱼、30 天保留文案。

主流程测试：

- `localStatsEnabled` 关闭时不写入统计，入口隐藏。
- `localStatsEnabled` 开启时可写入当天统计，入口显示。
- 复制或保存分享图成功后增加 `shareCount`。

验证命令：

- `node --test tests/local-stats-core.test.js`
- `node --test tests/index.test.js tests/styles.test.js`
- `npm test`
- `npm run build`
